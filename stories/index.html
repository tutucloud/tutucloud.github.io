    CORS problem detected

    The provider's API blocks direct browser requests. Install the llm-bridge extension and the app will send requests through it automatically.

    1. Open the folder D:\workspace\llm-bridge
    2. Chrome → chrome://extensions/ → enable Developer mode
    3. "Load unpacked" and select that folder
    4. Back in Settings, click "Save to llm-bridge extension"
